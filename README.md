
# YouTube Video Popularity Prediction Using AI

An advanced machine learning project with two prediction modes.

## Features
- Pre-upload popularity prediction
- Early-performance prediction
- Dataset analytics
- Model comparison
- Interactive Streamlit dashboard

## Technologies
Python, Streamlit, Pandas, NumPy, Scikit-learn and Plotly.

## Run locally
pip install -r requirements.txt
streamlit run app.py
